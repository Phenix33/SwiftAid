SwiftAid - Healthcare Management System

A PHP-based healthcare management platform with patient records, appointment scheduling, and secure authentication, built on XAMPP stack.

 Features

### Core Modules
- **Patient Management**
  - Electronic Health Records (EHR)
  - Appointment scheduling
  - Prescription tracking
- **Authentication System**
  - Email/password login
  - Google/Microsoft OAuth
  - Two-factor authentication
  - Role-based access control

### Technical Highlights
- 🛡️ Secure session management
- 📱 Responsive Bootstrap interface
- 🗃️ MySQL database integration
- 📊 Reporting dashboard

## Technology Stack

| Component       | Technology               |
|-----------------|--------------------------|
| **Frontend**    | HTML5, CSS3, JavaScript  |
| **Backend**     | PHP 8.1+                 |
| **Database**    | MySQL (via XAMPP)        |
| **Styling**     | Bootstrap 5 + Font Awesome |
| **Security**    | Prepared statements, password hashing |

## Local Development Setup

### Prerequisites
- [XAMPP](https://www.apachefriends.org/download.html) (v8.1+ recommended)
- PHP 8.1+
- MySQL 5.7+
- Composer (for optional dependencies)

1. **Start XAMPP Services**
   - Launch XAMPP Control Panel
